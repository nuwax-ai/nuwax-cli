# Product Overview

Nuwax CLI is a professional Docker service management and upgrade tool built in Rust. It provides complete lifecycle management for containerized applications including deployment, intelligent upgrades, backup, and maintenance.

## Core Purpose

Simplify Docker service operations for enterprise applications through:
- Intelligent multi-strategy upgrades (full, incremental, architecture-specific)
- Automated backup and rollback capabilities
- Cross-platform support (x86_64, aarch64)
- Real-time service monitoring and health checks

## Key Features

- **Smart Docker Management**: Complete container lifecycle with start/stop/restart/health checks
- **Intelligent Upgrades**: Automatic strategy selection between full and incremental upgrades
- **Backup System**: Automatic pre-upgrade backups with full rollback support
- **Architecture Detection**: Native support for x86_64 and ARM64 (Apple Silicon)
- **High Performance**: Built on Rust async runtime for exceptional concurrent performance
- **Modern CLI**: Intuitive interface with rich progress displays

## Target Users

DevOps engineers and system administrators managing containerized Docker services who need reliable, efficient upgrade and maintenance workflows.
